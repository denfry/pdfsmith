# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются только для последней версии из
[Releases](https://github.com/denfry/pdfsmith/releases/latest). Обновитесь
до последней версии, прежде чем сообщать о проблеме.

## Как сообщить об уязвимости

Не создавайте публичный Issue для уязвимостей. Используйте приватный отчёт
через GitHub: вкладка **Security** репозитория → **Report a vulnerability**
(раздел Security Advisories).

## Модель безопасности обновлений

- Проверка новых версий и загрузка дистрибутива идут только по HTTPS.
- Приложение обращается только к заранее заданным адресам GitHub
  (репозиторий и Releases) — список разрешённых источников зашит в код.
- Перед запуском установщика скачанный файл проверяется по контрольной
  сумме SHA-256 из манифеста релиза.
