## [0.1.2] - 2026-09-23

### Исправлено

- Программа не запускалась на ПК без видеокарты или без видеодрайвера
  («не найден ни один графический адаптер»): в сборку не попадал бэкенд
  DirectX 12. Теперь порядок такой: видеокарта (DirectX 12 / Vulkan) →
  программный DirectX 12 (WARP) → встроенный программный OpenGL (Mesa llvmpipe).
- Вместо аварийного окна — понятное сообщение, если отрисовка недоступна.

## [0.1.1] - 2026-09-23

### Добавлено

- Установщик `pdfsmith-setup.exe` (Inno Setup), установка без прав
  администратора в `%LocalAppData%\PDFsmith`.
- Обновления через GitHub Releases: плашка «Доступна версия …» и
  опциональная автоустановка в настройках.
- Предложение сделать PDFsmith приложением по умолчанию для PDF.
- Окно настроек приложения.
- CI (`cargo test`, сборка) и автоматический релиз по тегу `vX.Y.Z`.

## [0.1.0]

### Добавлено

- Первая версия просмотрщика PDF: тайловый рендер, прокрутка и зум,
  поиск по тексту, копирование текста, аннотации (карандаш, маркер, рамка,
  заметка) с отменой, операции со страницами (удалить, повернуть,
  переместить, вставить), сохранение поверх файла.
- Конвертер: PDF → PNG/JPEG, PDF → TXT, изображения → PDF, TXT → PDF,
  объединение и разделение PDF.
- Перетаскивание файлов для открытия и вставки страниц.
