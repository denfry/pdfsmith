# PDFsmith

Быстрый просмотрщик и редактор PDF для Windows. Rust, egui/wgpu, PDFium.

[![CI](https://github.com/denfry/pdfsmith/actions/workflows/ci.yml/badge.svg)](https://github.com/denfry/pdfsmith/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/denfry/pdfsmith)](https://github.com/denfry/pdfsmith/releases/latest)
![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11%20x64-blue)

Тайловый рендер в фоновом потоке, дисковый кэш, непрерывная лента страниц.

## Скачать

- [pdfsmith-setup.exe](https://github.com/denfry/pdfsmith/releases/latest/download/pdfsmith-setup.exe) — последняя версия
- [Все релизы](https://github.com/denfry/pdfsmith/releases)

Требования: Windows 10/11 x64. Права администратора не нужны — установка
per-user в `%LocalAppData%\PDFsmith`.

Установщик не подписан, поэтому при первом запуске SmartScreen может
показать предупреждение — нажмите «Подробнее» → «Выполнить в любом случае».
При последующих обновлениях (через сам PDFsmith) этот экран не появляется.

## Возможности

- **Просмотр:** прокрутка колесом по всем страницам, Ctrl+колесо — зум под
  курсором, вписать/по ширине, поворот вида, миниатюры страниц, экспорт в PNG (Ctrl+E).
- **Поиск** по тексту документа с подсветкой (Ctrl+F, F3), копирование текста
  выделением (инструмент «T»).
- **Аннотации:** карандаш, маркер, рамка, заметка; отмена последней (Ctrl+Z).
- **Страницы** (ПКМ по странице или миниатюре): удалить, повернуть, переместить,
  вставить пустую, вставить PDF, вставить изображения.
- **Сохранение** (Ctrl+S / Ctrl+Shift+S) — полная перезапись через временный
  файл.
- **Печать** (Ctrl+P): выбор принтера и его свойств, все/текущая/диапазон
  страниц, чётные/нечётные, копии с разбором, масштаб (по бумаге, 100 %,
  уменьшать крупные, свой), ориентация с автоповоротом, бумага, двусторонняя
  и чёрно-белая печать, пометки вкл/выкл, предпросмотр листа с полями.
- **Конвертер:** PDF → PNG/JPEG (72–600 DPI), PDF → TXT, изображения → PDF,
  TXT → PDF (Arial, перенос по словам, кириллица), объединение и разделение PDF.
- Перетаскивание: PDF — открыть, Shift+PDF — добавить в конец, изображения —
  вставить страницами.
- **Обновления** прямо из GitHub Releases, с опциональной автоустановкой
  (см. ниже и раздел «Настройки» в приложении).
- Приложение предлагает **стать программой по умолчанию** для PDF.

## Обновления

PDFsmith проверяет новые версии раз в 12 часов и по кнопке «Проверить
сейчас» в настройках. По умолчанию показывается плашка «Доступна версия …»;
с включённым переключателем «Автоматически устанавливать обновления»
дистрибутив скачивается в фоне и ставится при закрытии приложения. Перед
установкой скачанный файл проверяется по SHA-256. Если открыты другие окна
PDFsmith, установка откладывается до их закрытия.

## Сборка из исходников

```
cargo build --release
```

Рядом с `target/release/pdfsmith.exe` должна лежать `pdfium.dll` (PDFium
7xxx, x64). Для тестов та же DLL нужна в корне репозитория, а в `test_pdfs/`
— `text.pdf` (любой многостраничный PDF с текстовым слоем); без них тесты с
PDFium пропускаются.

Необязательно, но нужно для ПК без видеокарты: программный OpenGL Mesa
(`opengl32.dll` + `libgallium_wgl.dll`) рядом с `pdfsmith.exe`. Скачать в корень
репозитория: `pwsh installeretch-mesa.ps1` (затем скопировать в
`target/release/`). Установщик кладёт их автоматически.

```
cargo test --workspace
```

## Структура

- `crates/pdfsmith-pdfium` — тонкая обёртка над сырыми `FPDF_*`: рендер
  области страницы, текст/поиск, аннотации, операции со страницами,
  сохранение, создание документов из картинок и текста (`edit.rs`).
- `crates/pdfsmith-engine` — чистая математика: тайлы, LOD, LRU и дисковый кэш.
- `crates/pdfsmith-app` — UI. `render_thread.rs` — единственный поток,
  который зовёт PDFium (очередь задач, LRU загруженных страниц, отмена
  устаревших запросов тайлов); `app.rs` — состояние и панели; `theme.rs` —
  оформление.
- `crates/pdfsmith-update` — проверка версий, загрузка и проверка
  дистрибутива, запуск установщика.
- `installer/` — скрипт Inno Setup (`pdfsmith.iss`) и вспомогательные файлы
  сборки установщика.

## Переменные окружения

- `PDFSMITH_FORCE_WARP=1` — программный рендер (Mesa llvmpipe) вместо GPU.
- `RUST_LOG=info` — логи в stderr (в debug-сборке).

## Планы

- Вкладки — несколько открытых PDF в одном окне, один экземпляр приложения
  (двойной клик по PDF открывает вкладку в уже запущенном окне).
- Конвертация Word/Excel → PDF через MS Office, сжатие, установка пароля.
- OCR.
- Редактирование текста, водяные знаки, колонтитулы, скрытие данных.
- Конвертация PDF → Word/Excel.
